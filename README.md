# Jhon Acevedo - Web Portfolio

Bienvenido al repositorio del portfolio personal de **Jhon Acevedo** (QA Engineer, Creator, Builder). Este sitio web es una presentación profesional e interactiva que muestra su experiencia, habilidades, proyectos, estilo de vida y metas.

## 🚀 Características
- **Diseño único y creativo**: Interfaz oscura con acentos en tonos ámbar y una tipografía cautivadora (`Shippori Mincho`, `DM Mono`, `Syne`).
- **Secciones detalladas**:
  - **About:** Biografía y filosofía personal (Ikigai).
  - **Timeline:** Trayectoria profesional y eventos importantes.
  - **Work & Skills:** Servicios prestados y barras de progreso de habilidades.
  - **Setup:** Herramientas y hardware utilizados (Workspace).
  - **Interests & Lifestyle:** Intereses principales, top lists y estilo de vida.
  - **Thoughts, Goals & Wishlist:** Reflexiones, metas a futuro y lista de deseos.
- **Micro-interacciones completas**: Uso de CSS nativo para lograr transiciones suaves, barras de progreso de habilidades, grids responsivos y un diseño de tarjeta premium.
- **Responsivo**: Adaptable a diferentes tamaños de pantalla usando Flexbox y CSS Grid.

## 🛠 Tecnologías Utilizadas
- **HTML5**: Estructura semántica.
- **CSS3**: Estilos, variables CSS personalizadas, animaciones (`@keyframes`), y diseño adaptativo sin uso de frameworks de terceros.
- **Fuentes de Google**: Para la tipografía avanzada del sitio.

## 📥 Instalación y Uso
Este es un sitio web estático simple, por lo que no requiere instalación de dependencias ni procesos de compilación (build).

1. Clona el repositorio:
   ```bash
   git clone <URL_DEL_REPOSITORIO>
   ```
2. Abre la carpeta del proyecto.
3. Haz doble clic en el archivo `index.html` para abrirlo directamente en tu navegador web, o utiliza una extensión como **Live Server** en VSCode para una mejor experiencia de desarrollo.
